00
QUE ES ESTE ARCHIVO

index.html es UN SOLO ARCHIVO que contiene todo el juego: HTML, CSS, JavaScript, sprites pixelados (SVG inline), y datos de las casillas. No depende de ningun servidor ni de ninguna librería externa, salvo la fuente Press Start 2P que se carga desde Google Fonts.

Esto significa: si tienes el archivo, tienes el juego completo. Lo puedes abrir directamente desde el escritorio haciendo doble click, mandarlo por correo, subirlo a cualquier hosting, o usarlo offline (excepto la fuente, que requiere internet la primera vez).

ARCHIVO PRINCIPAL: index.html
TAMAÑO: APROX 35 KB
DEPENDENCIAS: NINGUNA (FUENTE OPCIONAL)

01
ESTRUCTURA DEL CODIGO

Si abres index.html en cualquier editor (VS Code, Sublime, hasta Notepad), vas a ver tres bloques grandes:

<style> // Todo el CSS del juego. // Variables de color en :root. </style> <body> // Solo dos divs vacios. // Todo se renderiza por JS. </body> <script> // La logica del juego. // Sprites, reglas, estado, render. </script>

Las secciones del JavaScript estan marcadas con comentarios. En orden de aparicion:

  • SPRITES · Las funciones spriteIgnacio() y spriteChicha(). Pixel art en SVG.
  • BOARD DESIGN · El path serpenteante 6x4 de 24 casillas.
  • DEFAULT_RULES · El array con las 24 casillas. Aqui editas el juego.
  • GAME STATE · El estado del juego (posiciones, turno, etc.).
  • ACTIONS · Funciones para tirar dado, mover, ganar.
  • RULE EDITING · Editor de casillas en vivo.
  • RENDER · Funciones que pintan la pantalla.
  • EVENT DELEGATION · Un solo handler para todos los clicks.
02
COMO PROBAR LOCAL

La forma mas simple:

  1. Doble click en index.html en el explorador de archivos.
  2. Se abre en tu navegador.
  3. Listo.

El juego guarda el progreso en el localStorage del navegador, asi que si lo abres por segunda vez en el mismo navegador, recupera el estado.

OJO: Cada navegador tiene su propio localStorage. Si lo abres en Chrome y despues en Safari, son partidas distintas.

Si quieres simular como se vería en un celular, abre las DevTools (F12) y activa el modo responsive (Ctrl+Shift+M en Chrome).

03
SUBIRLO A GITHUB PAGES

Asumiendo que ya conoces GitHub Pages, los pasos son:

  1. Crea un repo nuevo en GitHub. Nombre sugerido: microuniverso o similar. Puede ser publico o privado, GitHub Pages funciona en ambos en cuentas Pro.
  2. Sube index.html a la raiz del repo (no en una subcarpeta). Si quieres tambien sube los manuales (manual_jugador.html y manual_tecnico.html).
  3. Ve a Settings → Pages en el repo.
  4. En "Source" elige Deploy from a branch.
  5. Branch: main · Folder: / (root) · Save.
  6. En 1-2 minutos GitHub te da una URL tipo: https://[tu-usuario].github.io/microuniverso/
  7. Esa URL es la que les mandas por correo a Ignacio y Chicha.
TIP: Si quieres una URL mas corta, usa [tu-usuario].github.io como nombre del repo. Eso te da una URL sin subcarpeta.

Para editar despues: cualquier cambio que hagas al index.html y subas al repo se va a actualizar automaticamente en la URL en 1-2 minutos. Puedes editar directamente en GitHub usando el lapiz, o clonar el repo y editar local.

04
EDITAR LAS CASILLAS

Esta es la parte mas importante. Busca en index.html la linea que dice:

const DEFAULT_RULES = [

(Esta cerca de la linea 460, dentro del bloque <script>.) Despues de eso vienen las 24 casillas, cada una asi:

{ type: 'normal', icon: '♪', title: 'HNMUN', text: 'Boston 2017', desc: 'Galardones, perdigones, y una cerveza.' },

Solo cambia el texto entre comillas. No cambies el orden ni borres casillas — el tablero espera 24 exactas.

Los campos:

icon Simbolo grande en la casilla 1 caracter

05
CAMBIAR COLORES Y TEXTOS

Para cambiar la paleta de colores, busca el bloque :root al inicio del CSS:

:root { --bg: #0a0a23; // Fondo --bg-deep: #000010; // Fondo mas oscuro --cyan: #5cf2ff; // Casillas especiales --magenta: #ff5cd4; // Chicha / meta --yellow: #ffd23f; // Ignacio / bonus --green: #5cff7a; // Inicio --red: #ff3860; // Casillas peligro }

Cualquier color que cambies aqui se aplica a todo el juego. Usa codigos hexadecimales, formato #rrggbb.

Para cambiar la frase final del discurso en la pantalla de victoria, busca:

// Dentro de renderWin() '"EN EL JUEGO QUE USTEDES
ESTAN POR COMENZAR,
NO SOLO ESTA PERMITIDO
INVENTAR LAS REGLAS.
ESTA ENCOURAGED."'

Cambia el texto entre comillas. Usa <br> para saltos de linea.

06
LOS SPRITES PIXELADOS

Los muñequitos de Ignacio y Chicha son SVG inline dentro de las funciones spriteIgnacio() y spriteChicha(). Estan dibujados pixel por pixel en una grilla 16x16.

Cada linea es un pixel rectangular:

<rect x="5" y="6" width="1" height="1" fill="#1a1a1a"/>

x y y son la posicion (0-15), width y height son cuantos pixeles ocupa, fill es el color.

Si quieres modificar los sprites: cambia los fill para cambiar colores, o agrega mas <rect> para añadir detalles. No es facil sin una herramienta visual.

RECOMENDACION: Usa Piskelapp.com (gratis, en linea) para dibujar pixel art en 16x16, exporta como SVG, y reemplaza el contenido de la funcion. Tarda 10 minutos.

07
TROUBLESHOOTING

"El juego no carga"

  • Abre la consola del navegador (F12 → Console). Si hay errores rojos, mandame el screenshot.
  • Verifica que GitHub Pages haya terminado de hacer deploy (Settings → Pages, abajo dice "Your site is live at...").

"Los textos quedaron pegados a otros"

  • Probablemente excediste los limites de caracteres. Cuenta: title 14, text 18, desc 200.

"Quiero borrar todo el progreso guardado"

  • Abre el navegador donde se jugo. F12 → Application → Local Storage → encuentra la URL → borra la entrada microuniverso_v2.
  • Tambien puedes pedirles a ellos que abran en modo incognito.

"Quiero cambiar el numero total de casillas"

  • No es trivial. El path serpenteante esta calculado para 24 casillas (6x4). Si las cambias, tambien tienes que ajustar la funcion buildPath() y la constante TOTAL_CELLS.
  • Mas facil: deja 24, pero cambia los textos para reusar las que no necesites.

"Los acentos se ven raros"

  • Asegurate de que el archivo este guardado en UTF-8. La mayoria de editores ya lo hacen por defecto.
  • Si igual hay problemas, evita acentos en los textos. Yo puse las casillas sin acentos a proposito por compatibilidad con la fuente Press Start 2P.
